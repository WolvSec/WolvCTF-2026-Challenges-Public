To solve, you're intended to open up the program in a decompiler, search for main, and find that there are two function calls in the program. One of them returns a key and gives the user what they're supposed to send into the terminal, and the other is the one that sends the flag to the console. The latter is intended to be a harder way to get the solution, but will still work if the use recognizes that it's a simple Caesar cipher encrypting the flag. The intended way is to navigate to the key() function and read that the intended message is visible in plain sight if they read the characters being appended onto a string. Alternatively, if they feel like it, they can modify the program to make the check for having the right input on the prompt true, which is also a cool alternate route.
